# Visión y objetivos

## Visión
Un sistema de salud basado en la biología humana que transforme información en decisiones prácticas: qué comer, qué hábitos sostener y qué herramientas usar, siempre con la evidencia a la vista.

## Los cuatro sistemas
Cuatro sistemas conectados, alimentados por la misma base de conocimiento (este vault):

| # | Sistema | Función | Área del vault |
|---|---|---|---|
| 1 | Gestión de documentos | Base de conocimiento y de negocio; alimenta todo el contenido | Conocimiento + Negocio |
| 2 | Página web | Cara pública (cliente) y panel de administración | Web |
| 3 | Datos y analítica | Tests, perfiles y análisis | Web |
| 4 | Ventas y clientes | WhatsApp, carrito y pagos, CRM, embudo, logística | Operación |

**Flujo central:** bandeja → conocimiento → contenido (blogs, anuncios, fichas) → web → test → datos → perfil de cliente → venta → recompra.

Documento de origen: [[Plan integral del sistema (original 2026-10-03)]].

## Qué lo hace distinto
- **Trazabilidad**: cada afirmación tiene fuente y nivel de evidencia (A–F).
- **Tienda filtrada**: no hay productos "de sobra" ni "ricos nomás". Todo producto nutre o cumple una función biológica concreta, alineada a un protocolo del sistema.
- **Valor antes que venta**: cada producto llega con su ficha de valor y, luego, con un video de regalo.
- **Honestidad como marca**: la promesa nunca supera la evidencia.
- **Enfoque evolutivo**: nutrición ancestral, entorno, ritmos biológicos y bienestar integral, separando siempre evidencia, tradición y experiencia.

## Orden de construcción
1. Base de conocimiento + reglas de contenido (legal y tono).
2. Web con catálogo + test + captura de contacto + WhatsApp.
3. Carrito y pagos.
4. Logística básica (exportación por zona y franja).
5. Analítica de tests.
6. CRM, automatizaciones y campañas por segmento.
